## 起動

Node.js 22.12以上を使用します。`package.json` があるフォルダで実行します。

```bash
npm ci
npm run dev
```

[http://127.0.0.1:5176/](http://127.0.0.1:5176/) を開きます。依存パッケージの導入後、実行時の外部CDN接続は不要です。

```bash
npm run build
npm run preview
```

本番成果物は `dist/` です。配信については「[シリーズと公開設定](#シリーズと公開設定)」を参照してください。

## 操作

| タブ             | 主な操作                                                                   |
| ---------------- | -------------------------------------------------------------------------- |
| **つなぐ**       | 点を動かし、射影先とのずれを観察して、最上位の点を基準に整合化します。     |
| **落ち着く**     | 整合族を反復し、縮小率 `L ∈ [0,1.2]` と固定点への距離を調べます。          |
| **自分を表す**   | 現在の糸と表象を並べ、忠実な表象・表象なし・別の糸を指す表象を比較します。 |
| **履歴を変える** | 履歴Aを基準に履歴Bを動かし、層の区間と固定点の変化を共通座標で比較します。 |

常時表示は図・短い結果・主要操作を中心にしています。条件設定、7本の糸のギャラリー、距離グラフ、全ペア診断、数式・根拠、証明ガイドは必要なときにダイアログで開きます。タブ間で実験状態を保持し、ダイアログを開くと本編の反復を一時停止します。

初期状態は6層です。点はタップ・ドラッグ・矢印キーで動かせます。Home/Endは区間端点、Shift＋矢印は大きい刻みです。中空点は射影先で、整合を実線、不整合を破線で区別します。層数は2・3・4・6・8・12から選択でき、追加時は既存層の座標を保持します。履歴比較の図は読取専用です。

反復は1回進める操作と600msごとの再生に対応します。不整合族では開始できません。縮小率を変えると開始点へ戻り、同じ初期値で比較できます。`L=1` は恒等写像、`L>1` は複数固定点の例です。

Proof Engineは11段階の学習ガイドです。「前へ」「次へ」による移動・条件依存図・選択式の穴埋め5問を備えます。「図で確かめる」で対応するタブに戻ると、強調表示が残ります。自動証明や形式検証ではなく、非空性、固定点存在、一意性・反復収束、自己表象の追加条件を区別してたどる機能です。

「条件を変える」では、空集合・非コンパクト・不連続な射影・射影合成則・有限整合性・自己写像性・不連続な更新の7例を選べます。これらは本編のモデルを変更しない独立した数学例です。失われる保証と、その例で実際に成立する結論を分けて表示します。

## 数学モデル

層 `α` に対して、`c_α = 0.18 sin(1.7α)`、`r_α = 1 − 0.045α` とし、区間 `TCZ_α = [c_α−r_α,c_α+r_α]` を置きます。状態は `x_α = c_α + r_α z_α` です。

```text
π_{α←β}(x) = c_α + (r_α/r_β)(x − c_β)
SC_N = {(c_α + r_α z)_{α=0}^{N−1} : z ∈ [−1,1]}
e_{αβ} = |π_{α←β}(x_β) − x_α| / r_α
E_coh = Σ_{α<β} e_{αβ}²
d(S,T) = max_α |z_α(S) − z_α(T)|
```

射影は正規化座標を保存する連続アフィン全射で、恒等則・合成則を満たします。この有限モデルの `SC_N` は閉区間と同型の非空コンパクト凸集合です。全ての有限モデルの挙動から一般の無限逆極限の存在を数値的に証明したとは扱いません。`E_coh` は教材の診断量で、原典の中心式ではありません。

フィードバックは `q=0.2` として、共通座標に作用します。

```text
f(z) = clip(q + L(z−q), −1, 1)
F_SC_N((c_α + r_α z)_α) = (c_α + r_α f(z))_α
```

| L           | 固定点       | 保証                            |
| ----------- | ------------ | ------------------------------- |
| 0 ≤ L < 1   | z = q の一つ | 一意性・反復収束、d_n = L^n d_0 |
| L = 1       | 全ての z     | 存在するが一意ではない          |
| 1 < L ≤ 1.2 | z = −1, q, 1 | 存在するが一意ではない          |

切り詰めによって全てのLで区間内への連続自己写像を保ちます。非縮小時にも `q` までの距離を表示しますが、減衰上界は表示しません。境界固定点へ到達した場合、`q` までの距離はゼロになりません。

整合性は最大正規化誤差 `≤ 1e−8` で判定します。再生は、縮小時の距離 `< 1e−6`、一回の変化 `< 1e−9`、または200回で停止します。有限精度による停止を厳密な固定点の数値証明とは扱いません。

### 自己表象

教材用の表象空間を `Rep = {(z,z²) : z ∈ [−1,1]}` とし、`M(z) = (z,z²)` と定めます。第1座標から元の糸を復元できるため忠実です。

```text
decode(M(z)) = z
F_Rep(M(z)) = M(f(z))
F_Rep ∘ M = M ∘ F_SC_N
```

更新との両立は写像の定義による恒等式です。画面では現在点での誤差も表示します。自己表象の成立表示は、族の整合性・固定点性・忠実性・更新との両立・表象側の固定点性を確認します。表象を外しても本編の固定点は変わりません。「別の糸を指す」設定では正規化座標を0.25ずらした別の糸を表し、忠実性の条件を外します。

### 履歴比較

`h ∈ [−1,1]` を教材用の履歴パラメータとして、各層と目標座標を次のように変えます。

```text
c_α(h) = c_α + h(0.16 + 0.025α)
r_α(h) = r_α(1 + 0.18h)
q(h) = 0.2 + 0.45h
π^h_{α←β}(x) = c_α(h) + [r_α(h)/r_β(h)](x − c_β(h))
f_h(z) = clip(q(h) + 0.65(z−q(h)), −1, 1)
S*_h = (c_α(h) + r_α(h)q(h))_α
```

各履歴でも区間は非空コンパクトで、射影は正規化座標を保存します。履歴比較は `L=0.65` に固定した別モデルで、本編で選んだ `L` を保持します。A/Bの層と固定点は同じ座標軸で重ね、軸の拡大縮小によって変化が消えないようにしています。各履歴での固定点の一意性は、異なる履歴間で同じ固定点になることを意味しません。`h` は現実の人生の履歴を計測した値ではありません。

## 検証

リポジトリのルートで実行します。

```bash
npm test
npm run build
npm run test:e2e
npm run format:check
```

ブラウザテストには Playwright の Chromium が必要です。未導入の場合は `npx playwright install chromium` で準備します。

- モデルテスト25件：従来の射影・整合性・反復に加え、表象の復元と同変性、誤表象、履歴による層・射影・固定点、条件破壊の具体例を検証します。
- E2Eは5シナリオをPC・スマートフォンの2画面幅で実行します。4タブの状態保持、直接操作、ダイアログの開閉・フォーカス、反復と停止、自己表象、履歴比較、条件実験、証明ガイド・穴埋め、横幅を検証します。
- E2Eは本番ビルドを `/inverse-limit-lab/` に配信し、サブパスでのアセット読み込みも確認します。
